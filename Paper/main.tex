\section{Introduction}

\subsection{Problem Background}
Unit Commitment (UC) is a fundamental optimization problem in power system operation that determines the on/off status and generation levels of thermal units over a given time horizon. The primary goal is to minimize operating costs while satisfying demand and various system constraints. The UC problem is known to be a large-scale mixed integer programming (MIP) challenge, whose computational complexity grows exponentially with system size.

With the emergence of quantum optimization technologies such as the Coherent Ising Machine (CIM), the UC problem can be reformulated as a Quadratic Unconstrained Binary Optimization (QUBO) model. This transformation enables the use of quantum-inspired solvers for fast and parallel search of optimal solutions, paving the way for real-time power system operation on quantum hardware.

This competition invites participants to bridge classical power system optimization with quantum computing through a three-stage workflow: building a classical unit commitment model, transforming it into a QUBO formulation, and designing a scalable reduction strategy to accommodate current quantum hardware constraints.

\subsection{Problem Restatement}
Participants are required to construct a complete UC optimization framework that integrates both classical and quantum optimization methods. The problem consists of four sequential tasks:

\begin{enumerate}
\item \textbf{Classical UC Modeling and Optimization}: Formulate and solve a classical Unit Commitment model using conventional optimization tools (e.g., Gurobi or CPLEX), including fuel costs, startup/shutdown costs, power balance constraints, generation limits, minimum up/down time constraints, ramp-rate constraints, and startup/shutdown logic constraints.

\item \textbf{UC Modeling with Network and Security Constraints}: Extend the classical UC model to include network power flow constraints, N-1 security constraints, spinning reserve requirements, and optionally minimum safety inertia constraints.

\item \textbf{QUBO Transformation and Quantum Solution}: Transform the UC model into a QUBO representation and solve it using the Kaiwu SDK, comparing quantum-based solutions with traditional optimization results.

\item \textbf{Problem Scale Reduction under Quantum Hardware Constraints}: Design and implement an effective problem-scale reduction strategy specifically for the UC model to ensure the resulting QUBO can be successfully solved under the bit-capacity limitation of current quantum hardware.
\end{enumerate}

\subsection{Problem Analysis}
The UC problem presents significant computational challenges due to its combinatorial nature and large-scale characteristics. The classical approach involves solving a complex MIP problem with numerous constraints, while the quantum approach requires careful transformation of the problem into a QUBO format suitable for quantum solvers.

Key challenges include:
\begin{itemize}
\item \textbf{Combinatorial Complexity}: The binary decision variables for unit commitment status create an exponentially large solution space.
\item \textbf{Constraint Handling}: Multiple operational constraints must be satisfied simultaneously, including technical limits and security requirements.
\item \textbf{Model Transformation}: Converting the classical UC model into a QUBO formulation requires careful penalty parameter selection and constraint relaxation.
\item \textbf{Scale Reduction}: Current quantum hardware limitations necessitate effective problem reduction strategies to make real-world UC problems tractable.
\item \textbf{Solution Quality}: Ensuring that quantum solutions maintain feasibility and optimality comparable to classical approaches.
\end{itemize}

This paper addresses these challenges through a systematic approach that combines classical optimization techniques with emerging quantum computing methods, providing insights into the practical implementation of quantum optimization for power system applications.

\section{Assumptions}
To simplify the complex Unit Commitment problem and make it tractable for both classical and quantum optimization approaches, we make the following assumptions:

\begin{enumerate}
\item \textbf{Time Horizon Limitation}: The optimization is conducted over a 24-hour period only, focusing on short-term operational planning rather than long-term strategic decisions.

\item \textbf{Minimum Power Generation}: We assume that the minimum power generation values from Table 2 represent the true minimum operating limits for each unit, as Table 1 also contains minimum power values that may be inconsistent.

\item \textbf{Initial Operating Conditions}: If a unit is online at time 0, we assume it operates at its minimum power output level to establish a realistic starting condition for the optimization.

\item \textbf{Network Parameter Simplification}: We ignore the resistance (r) and susceptance (b) parameters from Table 3, focusing only on the reactance (x) values for DC power flow calculations, as these are the primary parameters affecting power flow distribution.

\item \textbf{Bus-Level Load Distribution}: Since the problem does not specify individual bus-level load demands, we treat bus-level load demands as optimization variables in Problem 2, allowing flexible load allocation across the network.

\item \textbf{Inertia Constraint Simplification}: Due to the unclear relationship between minimum inertia requirements (Hmin) and unit inertia constants (H), we do not consider inertia constraints in the optimization process, focusing instead on the core UC constraints.

\item \textbf{Deterministic Load Forecasting}: We assume perfect load forecasting for the 24-hour period, with no uncertainty in the load demand values provided in Table 4.

\item \textbf{Constant Fuel Prices}: Fuel prices and cost coefficients remain constant throughout the optimization horizon, with no consideration for fuel price volatility.

\item \textbf{No Transmission Losses}: We neglect transmission losses in the power system network, assuming that all generated power reaches the load centers without losses.

\item \textbf{Independent Unit Failures}: For N-1 security analysis, we assume that unit and line failures occur independently and that only single contingencies need to be considered.
\end{enumerate}

\section{Model Formulation}

\subsection{Problem 1: Classical Unit Commitment Model}

\subsubsection{Objective Function}
The objective is to minimize the total operating cost over the 24-hour horizon:
\[
\min \sum_{t\in\mathcal{T}} \sum_{i\in\mathcal{I}} \left[ a_i P_{i,t}^2 + b_i P_{i,t} + c_i u_{i,t} + SU_i y_{i,t} + SD_i z_{i,t} \right]
\]

\subsubsection{Constraints}
\begin{enumerate}
\item \textbf{Power Balance Constraint}:
\[
\sum_{i\in\mathcal{I}} P_{i,t} = D_t, \quad \forall t\in \mathcal{T}
\]

\item \textbf{Generation Limits}:
\[
P_i^{\min} u_{i,t} \le P_{i,t} \le P_i^{\max} u_{i,t}, \quad \forall i,t
\]

\item \textbf{Start-up/Shut-down Logic}:
\[
u_{i,t} - u_{i,t-1} = y_{i,t} - z_{i,t}, \quad \forall i,t
\]
\[
y_{i,t} + z_{i,t} \le 1, \quad \forall i,t
\]

\item \textbf{Minimum Up Time}:
\[
\sum_{\tau=t}^{t + UT_i - 1} u_{i,\tau} \ge UT_i \cdot y_{i,t}, \quad \forall i,t
\]

\item \textbf{Minimum Down Time}:
\[
\sum_{\tau=t}^{t + DT_i - 1} (1 - u_{i,\tau}) \ge DT_i \cdot z_{i,t}, \quad \forall i,t
\]

\item \textbf{Ramp-rate Limits}:
\[
P_{i,t} - P_{i,t-1} \le RU_i, \quad \forall i,t>1
\]
\[
P_{i,t-1} - P_{i,t} \le RD_i, \quad \forall i,t>1
\]
\end{enumerate}

\subsection{Problem 2: UC with Network and Security Constraints}

\subsubsection{Extended Objective Function}
The objective function remains the same as in Problem 1, but with additional constraints.

\subsubsection{Additional Constraints}
\begin{enumerate}
\item \textbf{Flexible Load Allocation}:
\[
D_{b,t} \ge 0, \quad \forall b,t
\]
\[
\sum_{b\in\mathcal{B}} D_{b,t} = D_t, \quad \forall t
\]

\item \textbf{DC Network Constraints}:
\begin{itemize}
\item \textbf{Bus Power Balance}:
\[
\sum_{i\in\mathcal{I}(b)} P_{i,t} - D_{b,t} = \sum_{\ell\in\delta^+(b)} F_{\ell,t} - \sum_{\ell\in\delta^-(b)} F_{\ell,t}, \quad \forall b,t
\]

\item \textbf{DC Power Flow}:
\[
F_{\ell,t} = \frac{\theta_{\text{from}(\ell),t} - \theta_{\text{to}(\ell),t}}{x_\ell}, \quad \forall \ell,t
\]

\item \textbf{Line Capacity Limits}:
\[
-F_\ell^{\max} \le F_{\ell,t} \le F_\ell^{\max}, \quad \forall \ell,t
\]

\item \textbf{Reference Bus}:
\[
\theta_{b_0,t} = 0, \quad \forall t
\]
\end{itemize}

\item \textbf{Spinning Reserve Constraints}:
\[
0 \le R_{i,t} \le P_i^{\max} u_{i,t} - P_{i,t}, \quad \forall i,t
\]

\item \textbf{N-1 Security Constraints}:
\begin{itemize}
\item \textbf{Generator Contingency Scenarios ($g \in \mathcal{C}^G$)}:
\[
P_{i,t}^{(g)} = P_{i,t} + \Delta P_{i,t}^{(g)}, \quad \forall i,t,g
\]
\[
P_{g,t}^{(g)} = 0, \quad \forall t,g
\]
\[
0 \le \Delta P_{i,t}^{(g)} \le R_{i,t}, \quad \forall i,t,g
\]
\[
\sum_{i\in\mathcal{I}(b)} P_{i,t}^{(g)} - D_{b,t} = \sum_{\ell\in\delta^+(b)} F_{\ell,t}^{(g)} - \sum_{\ell\in\delta^-(b)} F_{\ell,t}^{(g)}, \quad \forall b,t,g
\]

\item \textbf{Line Contingency Scenarios ($\ell \in \mathcal{C}^L$)}:
\[
P_{i,t}^{[\ell]} = P_{i,t} + \Delta P_{i,t}^{[\ell]}, \quad \forall i,t,\ell
\]
\[
F_{\ell,t}^{[\ell]} = 0, \quad \forall t,\ell
\]
\[
0 \le \Delta P_{i,t}^{[\ell]} \le R_{i,t}, \quad \forall i,t,\ell
\]
\[
\sum_{i\in\mathcal{I}(b)} P_{i,t}^{[\ell]} - D_{b,t} = \sum_{\ell'\in\delta^+(b)} F_{\ell',t}^{[\ell]} - \sum_{\ell'\in\delta^-(b)} F_{\ell',t}^{[\ell]}, \quad \forall b,t,\ell
\]
\end{itemize}
\end{enumerate}

\subsection{Problem 3: QUBO Transformation}

\subsubsection{QUBO Formulation}
The UC problem is transformed into a Quadratic Unconstrained Binary Optimization (QUBO) problem:
\[
\min \mathbf{x}^T Q \mathbf{x}
\]
where $\mathbf{x}$ is a binary vector representing all decision variables, and $Q$ is a symmetric matrix encoding the objective function and constraints.

\subsubsection{Constraint Handling}
Constraints are incorporated into the QUBO formulation using penalty terms:
\[
Q = Q_{\text{objective}} + \sum_k \lambda_k Q_{\text{constraint}_k}
\]
where $\lambda_k$ are penalty coefficients that ensure constraint satisfaction.

\subsubsection{Variable Encoding}
Binary variables are used to represent:
\begin{itemize}
\item Unit commitment status $u_{i,t}$
\item Start-up and shut-down indicators $y_{i,t}, z_{i,t}$
\item Discretized power output levels
\item Network variables in binary form
\end{itemize}

\subsubsection{Kaiwu SDK Implementation}
The QUBO model is solved using the Kaiwu SDK quantum solver, which employs quantum-inspired algorithms to find near-optimal solutions efficiently.

\section{Results and Analysis}

\subsection{Problem 1: Classical UC Results}
The classical Unit Commitment model was successfully solved using Gurobi optimization solver. The results demonstrate efficient economic dispatch with the following key observations:

\begin{itemize}
\item \textbf{Cost Performance}: The total operating cost was minimized while satisfying all operational constraints, with fuel costs, startup costs, and shutdown costs properly accounted for in the objective function.

\item \textbf{Unit Commitment Pattern}: The heatmap visualization (Figure 1) shows that:
\begin{itemize}
\item Units U1 and U2 operate as base load units, maintaining high output levels throughout most of the day due to their large capacity and favorable cost characteristics.
\item Units U5 and U8 serve as intermediate load units, adjusting their output to follow load variations with medium power generation levels.
\item Units U11 and U13 function as peaking units, operating primarily during high-demand periods to provide additional capacity.
\end{itemize}

\item \textbf{Load Following}: The stacked unit outputs (Figure 2) precisely track the system load demand curve, confirming that the power balance constraint is satisfied at all time periods.

\item \textbf{Constraint Satisfaction}: All technical constraints including minimum up/down times, ramp-rate limits, and generation limits were strictly enforced, resulting in a feasible and reliable commitment schedule.
\end{itemize}

\subsection{Problem 2: Network-Constrained UC Results}
The extended UC model with network and security constraints was solved, revealing important system-level insights:

\begin{itemize}
\item \textbf{Network Impact}: The inclusion of DC power flow constraints significantly affected unit commitment decisions, particularly for units located at network-constrained buses.

\item \textbf{Security Enhancement}: The N-1 security constraints ensured system reliability under single contingency scenarios, with adequate spinning reserve allocation to handle generator and line outages.

\item \textbf{Cost Comparison}: Compared to Problem 1, the total operating cost increased due to the additional security requirements and network constraints, demonstrating the trade-off between economic efficiency and system reliability.

\item \textbf{Load Distribution}: The flexible load allocation allowed optimal distribution of load across buses, minimizing transmission congestion and improving overall system efficiency.
\end{itemize}

\subsection{Problem 3: QUBO Transformation Results}
The quantum-based approach using Kaiwu SDK provided the following results:

\begin{itemize}
\item \textbf{Solution Quality}: The QUBO formulation successfully captured the essential features of the UC problem, though with some approximation due to the binary encoding of continuous variables.

\item \textbf{Computational Performance}: The quantum solver demonstrated competitive solution times for the transformed problem, particularly for smaller problem instances.

\item \textbf{Constraint Handling}: The penalty-based constraint enforcement in the QUBO formulation required careful parameter tuning to balance objective optimization and constraint satisfaction.

\item \textbf{Comparison with Classical Methods}: While the quantum solution provided feasible schedules, the classical optimization approach generally achieved better objective values due to its ability to handle continuous variables more precisely.
\end{itemize}

\subsection{Comparative Analysis}
The three approaches demonstrate complementary strengths:
\begin{itemize}
\item \textbf{Classical UC (Problem 1)}: Provides the most economically efficient solution but lacks network and security considerations.
\item \textbf{Network-Constrained UC (Problem 2)}: Offers enhanced reliability at the cost of increased operating expenses.
\item \textbf{Quantum Approach (Problem 3)}: Shows promise for future scalability but currently faces limitations in solution quality and problem size constraints.
\end{itemize}

\section{Strengths and Weaknesses}

\subsection{Strengths of Our Approach}

\begin{description}
\item[Comprehensive Model Integration] Our framework successfully integrates classical optimization methods with emerging quantum computing techniques, providing a complete workflow from traditional UC modeling to quantum-based solution approaches.

\item[Multi-Constraint Handling] The models effectively handle diverse constraint types including economic, technical, network, and security constraints, demonstrating robust constraint satisfaction across different problem formulations.

\item[Scalable Architecture] The modular design allows for systematic problem extension from basic UC to network-constrained and security-enhanced formulations, providing a scalable framework for power system optimization.

\item[Quantum-Classical Comparison] By implementing both classical and quantum approaches, we provide valuable insights into the comparative performance and applicability of different optimization paradigms for UC problems.

\item[Practical Assumptions] The assumptions made in our models are realistic and aligned with industry practices, ensuring that the solutions are practically implementable in real power systems.
\end{description}

\subsection{Weaknesses and Limitations}

\begin{description}
\item[Computational Complexity] The classical UC formulation remains computationally intensive for large-scale systems, with solution times growing exponentially with problem size.

\item[Quantum Hardware Limitations] Current quantum hardware constraints significantly limit the problem size that can be handled by quantum solvers, requiring substantial problem reduction for practical implementation.

\item[Solution Quality Trade-offs] The QUBO transformation introduces approximations that may compromise solution quality compared to exact classical methods, particularly for continuous variables.

\item[Network Simplifications] The DC power flow approximation neglects reactive power considerations and transmission losses, which may affect solution accuracy in heavily loaded systems.

\item[Deterministic Framework] Our models assume perfect load forecasting and deterministic parameters, not accounting for uncertainties in renewable generation, load variations, or equipment failures.
\end{description}

\subsection{Areas for Improvement}

\begin{itemize}
\item \textbf{Hybrid Approaches}: Future work could explore hybrid classical-quantum algorithms that leverage the strengths of both approaches while mitigating their individual limitations.

\item \textbf{Uncertainty Modeling}: Incorporating stochastic optimization techniques to handle uncertainties in load forecasting, renewable generation, and equipment availability.

\item \textbf{Advanced Network Models}: Extending the network model to include AC power flow constraints and reactive power considerations for more accurate system representation.

\item \textbf{Real-time Applications}: Developing real-time UC formulations that can adapt to changing system conditions and provide operational flexibility.

\item \textbf{Quantum Algorithm Enhancement}: Improving quantum algorithms and hardware capabilities to handle larger problem instances with better solution quality.
\end{itemize}

\subsection{Problem Reduction Strategy}

\begin{itemize}

\item \textbf{Time Horizon Reduction}: Focused on critical time periods (peak and valley hours) while maintaining solution quality.

\item \textbf{Constraint Relaxation}: Relaxed non-critical constraints and used penalty-based enforcement in QUBO formulation.

\item \textbf{Binary Encoding Optimization}: Used efficient binary encoding schemes for continuous variables to minimize qubit requirements.

\item \textbf{Problem Decomposition}: Applied decomposition techniques to solve smaller subproblems and combine results.
\end{itemize}
