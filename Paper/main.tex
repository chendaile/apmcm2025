\section{引言}
问题 D 要求在 30 节点系统内完成 24 小时机组组合与安全校核。赛题数据包含机组出力上下限、启停成本、爬坡、惯量系数（Table 1/2/5）、支路阻抗与潮流上限（Table 3）以及系统负荷曲线（Table 4）。\texttt{output} 目录已经给出两组求解结果：问题 1 的经典 UC 解与问题 2 的含潮流、备用及 N--1 约束解。本文根据这些成果整理出完整的论文叙述结构，并补充可视化图像以支撑论证。

\section{问题描述}
\subsection{研究对象}
\begin{itemize}
  \item \textbf{问题 1：经典 UC}。忽略电网拓扑，仅在系统层面平衡负荷并最小化燃料成本与启停成本。
  \item \textbf{问题 2：安全约束 UC}。在问题 1 的基础上引入 DC 潮流、母线柔性负荷分配、旋转备用与惯量要求，并对每台机组、每条线路进行 N--1 备用校核。
\end{itemize}

\subsection{目标与判据}
两类模型的目标函数均为 24 小时累积成本最小化（燃料二次函数 + 启停成本）。评估指标包括：
\begin{itemize}
  \item 日总成本（输出日志中最优值均为 15,129.08 美元）。
  \item 出力曲线与负荷曲线的吻合度。
  \item 潮流与柔性负荷的可行性，以及备用/惯量裕度。
\end{itemize}

\section{模型与求解方法}
\subsection{经典机组组合模型（问题 1）}
模型将每台机组的出力 \(p_{i,t}\)、开机状态 \(u_{i,t}\)、启停决策 \(y_{i,t}, z_{i,t}\) 建模为混合整数变量，目标函数为燃料成本二次项与启停成本之和。约束包含：
\begin{itemize}
  \item 系统功率平衡：\(\sum_i p_{i,t} = L_t\)。
  \item 出力上下界、爬坡率、最小开机/停机时间及启停逻辑（\(y+z\le 1\)）。
  \item 初始状态继承：根据表中给定的已开机/停机时长锁定前若干时段的状态。
\end{itemize}
Gurobi 求解器在 0.03s 内获得全局最优解，日总成本 15,129.08。

\subsection{含潮流与备用的安全约束 UC（问题 2）}
在上述模型上增加以下要素：
\begin{itemize}
  \item \textbf{DC 潮流与母线负荷分配}：以参考母线为零相角，\(f_\ell = (\theta_{fr}-\theta_{to})/x_\ell\)，并限制支路潮流不超过 \(F^{\max}_\ell\)。柔性负荷变量 \(d_{b,t}\ge0\) 在各母线间分配，总和等于系统负荷。
  \item \textbf{旋转备用与惯量}：每台机组备用 \(r_{i,t}\) 不超过可用余量，惯量约束 \(\sum_i H_i u_{i,t}\ge H_{\min}\)。输出结果显示备用总量可视化（图 \ref{fig:reserve}）。
  \item \textbf{N--1 校核}：为每个机组停运场景 \(p^{cg}_{i,g,t}\) 与线路停运场景 \(p^{cl}_{i,\ell,t}\) 新建潮流平衡与备用收缩变量，保证在任一单元件失效时仍可由备用补偿且不越线。
\end{itemize}
求解耗时约 9.6s，最优成本同样为 15,129.08，表明安全约束未显著抬升费用。

\section{结论与展望}
\subsection{主要结论}
\begin{itemize}
  \item 已有输出展示了可行的机组组合与潮流分配，日成本 15,129.08，美观的出力曲线与负荷吻合度为撰写结果分析提供了依据。
  \item N--1 校核与柔性负荷分配在现有求解中保持可行，但系统级旋转备用需求尚未强制满足，应在后续版本补全。
  \item 所生成的可视化图像（图 \ref{fig:q1_dispatch}--\ref{fig:reserve}）可直接嵌入论文，支撑对调度规律、备用裕度与潮流分配的论述。
\end{itemize}

\subsection{方法总结}
本文基于混合整数规划与 DC 潮流线性化，结合 Gurobi 求解器快速获得全局最优解；通过 Python 脚本自动化导出变量与图像，可复用性强。

\subsection{后续改进方向}
\begin{itemize}
  \item 恢复并调优系统级旋转备用约束，验证成本与可行域变化；
  \item 尝试引入惯量成本或动态安全因子，以便与频率约束更紧耦合；
  \item 对柔性负荷增加上下限或经济性权重，提升物理合理性。
\end{itemize}
