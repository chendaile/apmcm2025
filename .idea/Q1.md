# **Problem 1：Classical Unit Commitment Model**

## **1. 符号说明（Notation）**

### **1.1 集合（Sets）**

| 符号              | 含义               |
| --------------- | ---------------- |
| ( \mathcal{I} ) | 机组集合（units）      |
| ( \mathcal{T} ) | 时间集合（例如 1–24 小时） |

---

### **1.2 参数（Parameters）**

#### **（1）机组出力参数**

| 符号         | 含义                      |
| ------------ | ------------------------- |
| (P_i^{\min}) | 机组 (i) 的最小出力（MW） |
| (P_i^{\max}) | 机组 (i) 的最大出力（MW） |

---

#### **（2）成本参数**

| 符号            | 含义                                                    |
| --------------- | ------------------------------------------------------- |
| (a_i, b_i, c_i) | 机组 (i) 的燃料成本系数（用于 (a_i P^2 + b_i P + c_i)） |
| (SU_i)          | 机组 (i) 的启动成本（Start-up cost）                    |
| (SD_i)          | 机组 (i) 的停机成本（Shut-down cost）                   |

---

#### **（3）机组运行技术参数**

| 符号    | 含义                                |
| ------- | ----------------------------------- |
| (UT_i)  | 最小开机时间（Minimum Up Time）     |
| (DT_i)  | 最小停机时间（Minimum Down Time）   |
| (RU_i)  | 爬坡上限（Ramp-up limit）           |
| (RD_i)  | 下坡上限（Ramp-down limit）         |
| (U_i^0) | 机组 (i) 初始状态（开机=1，停机=0） |
| (T_i^0) | 初始开/停机时长（小时）             |

---

#### **（4）系统负荷数据**

| 符号  | 含义                            |
| ----- | ------------------------------- |
| (D_t) | 时段 (t) 的全系统负荷需求（MW） |

---

### **1.3 决策变量（Decision Variables）**

#### **（1）二元变量**

| 符号       | 类型 | 含义                         |
| ---------- | ---- | ---------------------------- |
| (u\_{i,t}) | 0/1  | 机组 (i) 在 (t) 时段是否开机 |
| (y\_{i,t}) | 0/1  | 是否在 (t) 时段启动机组 (i)  |
| (z\_{i,t}) | 0/1  | 是否在 (t) 时段停机机组 (i)  |

#### **（2）连续变量**

| 符号       | 类型 | 含义                             |
| ---------- | ---- | -------------------------------- |
| (P\_{i,t}) | 连续 | 机组 (i) 在 (t) 时段的出力（MW） |

---

# **2. 经典 UC 模型（Classical UC Model）**

## **2.1 目标函数**

最小化总运行成本：

[
\min
\sum*{t\in\mathcal{T}}
\sum*{i\in\mathcal{I}}
\left[
a*i P*{i,t}^2 + b*i P*{i,t} + c*i u*{i,t}

- SU*i y*{i,t} + SD*i z*{i,t}
  \right]
  ]

---

## **2.2 约束条件**

---

### **(1) 功率平衡（Power Balance）**

[
\sum_{i\in\mathcal{I}} P_{i,t} = D_t,
\quad \forall t\in \mathcal{T}
]

---

### **(2) 出力限制（Generation Limits）**

[
P_i^{\min} u_{i,t} \le P_{i,t} \le P_i^{\max} u_{i,t},
\quad \forall i,t
]

---

### **(3) 启停逻辑（Start-up / Shut-down Logic）**

[
u_{i,t} - u_{i,t-1} = y_{i,t} - z_{i,t},
\quad \forall i,t
]

禁止同一时段既启动又停机：

[
y_{i,t} + z_{i,t} \le 1,
\quad \forall i,t
]

---

### **(4) 最小开机时间（Minimum Up Time）**

若启动，则必须连续开机至少 (UT_i) 小时：

[
\sum_{\tau=t}^{t + UT_i - 1} u_{i,\tau}
\ge UT_i \cdot y_{i,t},
\quad \forall i,t
]

---

### **(5) 最小停机时间（Minimum Down Time）**

若停机，则必须连续停机至少 (DT_i) 小时：

[
\sum_{\tau=t}^{t + DT_i - 1} (1 - u_{i,\tau})
\ge DT_i \cdot z_{i,t},
\quad \forall i,t
]

---

### **(6) 爬坡约束（Ramp-rate Limits）**

[
P_{i,t} - P_{i,t-1} \le RU_i,
\quad \forall i,t>1
]

[
P_{i,t-1} - P_{i,t} \le RD_i,
\quad \forall i,t>1
]
