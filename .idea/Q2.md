# **Problem 2：UC with Network, N−1 Security, Spinning Reserve, Inertia, and Flexible Load Allocation**

## **1. Sets and Indices**

* ( \mathcal{I} )：机组集合（units）
* ( \mathcal{B} )：母线集合（buses）
* ( \mathcal{L} )：线路集合（branches/lines）
* ( \mathcal{T} = {1,\dots,T} )：时段集合（本题 (T = 24)）

严格 N−1 场景集合：

* ( \mathcal{C}^G = \mathcal{I} )：每台机组 (g) 故障的场景
* ( \mathcal{C}^L = \mathcal{L} )：每条线路 (\ell) 故障的场景
---

# **2. Parameters**

## **2.1 机组参数（Table 1–2）**

- (P_i^{\min}, P_i^{\max})：最小/最大出力
- (a_i,b_i,c_i)：燃料成本系数
- (SU_i,SD_i)：启停成本
- (UT_i,DT_i)：最小开停机时间
- (RU_i,RD_i)：爬坡上/下限
- (H_i)：机组惯量常数

## **2.2 网络参数（Table 3）**

- (x\_\ell)：线路电抗
- (F\_\ell^{\max})：线路容量
- (\text{from}(\ell))、(\text{to}(\ell))：线路端点
- (\mathcal{I}(b))：连接到 bus (b) 的机组集合
- (\delta^+(b))：以 bus (b) 为起点的线路
- (\delta^-(b))：以 bus (b) 为终点的线路

## **2.3 系统总负荷（Table 4）**

- (D*t)：系统总负荷（(\sum_b D*{b,t} = D_t)）

> **本题不提供 bus-level 负荷，故由模型优化确定**

## **2.4 备用与惯性参数（Table 5）**

- 负荷阶跃：(\Delta P^{\text{step}} = 600\text{MW})
- ROCOF 上限：(\text{ROCOF}^{\max} = 0.5\text{Hz/s})
- 系统频率常数：(F = 2.118)

旋转备用需求：

[
R_t = 600,\quad \forall t
]

最小惯量需求：

[
H^{\min} = \frac{600}{2 \cdot F \cdot \text{ROCOF}^{\max}}
]

---

# **3. Decision Variables**

## **3.1 基态（正常工况）**

- (u\_{i,t} \in {0,1})：机组状态
- (y*{i,t}, z*{i,t} \in {0,1})：启动/停机指示
- (P\_{i,t} \ge 0)：机组出力
- (\theta\_{b,t})：母线相角
- (F\_{\ell,t})：线路潮流
- (R\_{i,t} \ge 0)：机组备用
- **(D\_{b,t} \ge 0)：bus-level 负荷（优化变量）**

## **3.2 机组故障场景 (g)**

- (P*{i,t}^{(g)})、(\Delta P*{i,t}^{(g)})
- (\theta*{b,t}^{(g)})、(F*{\ell,t}^{(g)})

## **3.3 线路故障场景 (\ell)**

- (P*{i,t}^{[\ell]})、(\Delta P*{i,t}^{[\ell]})
- (\theta*{b,t}^{[\ell]})、(F*{\ell',t}^{[\ell]})

---

# **4. Objective Function**

[
\min
\sum*{t}\sum*{i}
\left(
a*i P*{i,t}^2 + b*i P*{i,t} + c*i u*{i,t}

- SU*i y*{i,t} + SD*i z*{i,t}
  \right)
  ]

---

# **5. Classical UC Constraints**

## **5.1 出力上下限**

[
P_i^{\min}u_{i,t} \le P_{i,t} \le P_i^{\max}u_{i,t}
]

## **5.2 启停逻辑**

[
u_{i,t}-u_{i,t-1}=y_{i,t}-z_{i,t}
]

[
y_{i,t}+z_{i,t} \le 1
]

## **5.3 最小开停机时间**

[
\sum_{\tau=t}^{t+UT_i-1} u_{i,\tau} \ge UT_i y_{i,t}
]

[
\sum_{\tau=t}^{t+DT_i-1} (1-u_{i,\tau}) \ge DT_i z_{i,t}
]

## **5.4 爬坡约束**

[
P_{i,t}-P_{i,t-1} \le RU_i
]

[
P_{i,t-1}-P_{i,t} \le RD_i
]

---

# **6. Flexible Load Allocation Constraints**（你要求的新部分）

## **6.1 负荷非负**

[
D_{b,t} \ge 0,\quad \forall b,t
]

## **6.2 每时段总负荷保持为 Table 4 数值**

[
\sum_{b\in\mathcal{B}} D_{b,t} = D_t,\quad \forall t
]

---

# **7. 基态 DC 网络约束**

## **7.1 母线功率平衡**

[
\sum*(b)} P* - D\_
=================

## \sum*F*

\sum*{\ell\in\delta^-(b)}F*{\ell,t}
]

## **7.2 DC 潮流**

[
F_{\ell,t} = \frac{\theta_{\text{from}(\ell),t}-\theta_{\text{to}(\ell),t}}{x_\ell}
]

## **7.3 线路容量**

[
-F_\ell^{\max} \le F_{\ell,t} \le F_\ell^{\max}
]

## **7.4 参考母线**

[
\theta_{b_0,t} = 0
]

---

# **8. Spinning Reserve Constraints**

## **8.1 单机备用能力**

[
0 \le R_{i,t} \le P_i^{\max} u_{i,t} - P_{i,t}
]

## **8.2 系统备用**

[
\sum_{i} R_{i,t} \ge 600
]

---

# **9. Minimum Inertia Constraint**

[
\sum_{i} H_i u_{i,t} \ge H^{\min}
]

---

# **10. N−1: 机组故障场景**

## **10.1 出力增量关系**

[
P_{i,t}^{(g)} = P_{i,t} + \Delta P_{i,t}^{(g)}
]

## **10.2 故障机组停运**

[
P_{g,t}^{(g)} = 0
]

## **10.3 再调度约束**

[
0 \le \Delta P_{i,t}^{(g)} \le R_{i,t}
]

[
0 \le P_{i,t}^{(g)} \le P_i^{\max}u_{i,t}
]

## **10.4 节点平衡**

[
\sum*(b)} P*^ - D\_
==================

## \sum*F*^

\sum*{\ell\in\delta^-(b)}F*{\ell,t}^{(g)}
]

## **10.5 DC 潮流**

[
F_{\ell,t}^{(g)} =
\frac{\theta_{\text{from}(\ell),t}^{(g)}-\theta_{\text{to}(\ell),t}^{(g)}}{x_\ell}
]

## **10.6 线路限额**

[
-F_\ell^{\max} \le F_{\ell,t}^{(g)} \le F_\ell^{\max}
]

## **10.7 参考母线**

[
\theta_{b_0,t}^{(g)} = 0
]

---

# **11. N−1: 线路故障场景**

## **11.1 出力增量关系**

[
P*{i,t}^{[\ell]} = P*{i,t} + \Delta P\_{i,t}^{[\ell]}
]

## **11.2 再调度限制**

[
0 \le \Delta P*{i,t}^{[\ell]} \le R*{i,t}
]

[
0 \le P*{i,t}^{[\ell]} \le P_i^{\max} u*{i,t}
]

## **11.3 故障线路切除**

[
F\_{\ell,t}^{[\ell]} = 0
]

## **11.4 节点平衡**

[
\sum*(b)} P*^ - D\_
==================

## \sum*F*^

\sum*{\ell'\in\delta^-(b)}F*{\ell',t}^{[\ell]}
]

## **11.5 DC 潮流（其它线路）**

[
F*{\ell',t}^{[\ell]} =
\frac{\theta*{\text{from}(\ell'),t}^{[\ell]} - \theta*{\text{to}(\ell'),t}^{[\ell]}}{x*{\ell'}},
\quad \ell'\neq\ell
]

## **11.6 限额**

[
-F*{\ell'}^{\max} \le F*{\ell',t}^{[\ell]} \le F\_{\ell'}^{\max}
]

## **11.7 参考母线**

[
\theta\_{b_0,t}^{[\ell]} = 0
]
