# Problem 2：UC with Network, Security and Inertia Constraints

## 1. Sets and Indices

* ( \mathcal{I} )：机组集合（units）
* ( \mathcal{B} )：母线集合（buses）
* ( \mathcal{L} )：线路集合（branches/lines）
* ( \mathcal{T} = {1,\dots,T} )：时段集合（本题 (T=24)）

严格 N−1 场景集合：

* ( \mathcal{C}^G = \mathcal{I} )：每个 (g \in \mathcal{C}^G) 表示“机组 (g) 故障”场景
* ( \mathcal{C}^L = \mathcal{L} )：每个 (\ell \in \mathcal{C}^L) 表示“线路 (\ell) 故障”场景
---
## 2. Parameters

### 2.1 机组参数（来自 Table 1–2）

- (P_i^{\min}, P_i^{\max})：机组 (i) 出力上下限（MW）
- (a_i,b_i,c_i)：机组燃料成本系数（(a_i P^2 + b_i P + c_i)）
- (SU_i,SD_i)：机组 (i) 启动 / 停机成本
- (UT_i,DT_i)：最小开机 / 停机时间（h）
- (RU_i,RD_i)：爬坡上 / 下限（MW/h）
- (H_i)：机组 (i) 惯量常数（来自表中 H 列）

### 2.2 网络与负荷参数（来自 Table 3–4）

- (x\_\ell)：线路 (\ell) 的电抗（p.u.）
- (F\_\ell^{\max})：线路 (\ell) 的有功传输上限（MW）
- (D*{b,t})：母线 (b) 在时段 (t) 的负荷（要求 (\sum*{b\in\mathcal{B}} D\_{b,t} = D_t^{\text{(Table 4)}})）
- (\mathcal{I}(b)\subseteq\mathcal{I})：接在母线 (b) 上的机组集合
- (\text{from}(\ell), \text{to}(\ell)\in\mathcal{B})：线路 (\ell) 的起始母线
- (\delta^+(b))：以 (b) 为起点的线路集合
- (\delta^-(b))：以 (b) 为终点的线路集合

### 2.3 备用与惯性相关参数（来自 Table 5）

- 负荷阶跃（load step）：(\Delta P^{\text{step}} = 600\ \text{MW})
- ROCOF 上限：(\text{ROCOF}^{\max} = 0.5\ \text{Hz/s})
- 频率相关系数：(F = 2.118)

系统旋转备用需求取为：

[

R_t = \Delta P^{\text{step}} = 600,\quad \forall t\in\mathcal{T}.

]

系统最小惯量需求：

[

H^{\min}

= \frac{\Delta P^{\text{step}}}{2 F \cdot \text{ROCOF}^{\max}}

= \frac{600}{2 \cdot 2.118 \cdot 0.5}.

]

---

## 3. Decision Variables

### 3.1 基态（正常工况）

- (u\_{i,t} \in {0,1})：机组 (i) 在时段 (t) 是否开机
- (y*{i,t},z*{i,t} \in {0,1})：机组 (i) 在时段 (t) 是否启动 / 停机
- (P\_{i,t} \ge 0)：机组 (i) 在时段 (t) 的出力（MW）
- (\theta\_{b,t})：母线 (b) 在时段 (t) 的相角
- (F\_{\ell,t})：线路 (\ell) 在时段 (t) 的潮流（MW）
- (R\_{i,t} \ge 0)：机组 (i) 在时段 (t) 的旋转备用容量（MW）

### 3.2 机组故障场景 (g \in \mathcal^G)

- (P\_{i,t}^{(g)})：场景 “机组 (g) 故障” 时机组 (i) 的出力
- (\Delta P\_{i,t}^{(g)})：该场景相对基态的出力增量
- (\theta\_{b,t}^{(g)})：该场景下母线相角
- (F\_{\ell,t}^{(g)})：该场景下线路潮流

### 3.3 线路故障场景 (\ell \in \mathcal^L)

- (P\_{i,t}^{[\ell]})：场景 “线路 (\ell) 故障” 时机组 (i) 的出力
- (\Delta P\_{i,t}^{[\ell]})：该场景相对基态的出力增量
- (\theta\_{b,t}^{[\ell]})：该场景下母线相角
- (F\_{\ell',t}^{[\ell]})：该场景下线路 (\ell') 的潮流

> 注意：所有场景中 **(u*{i,t},y*{i,t},z*{i,t},R*{i,t})** 与基态相同，不随故障改变。

---

## 4. Objective Function

与 Problem 1 一致：最小化全过程燃料成本 + 启停成本：

[

\min

\sum\_{t\in\mathcal{T}}

\sum\_{i\in\mathcal{I}}

\Big(

a*i P*{i,t}^2 + b*i P*{i,t} + c*i u*{i,t}

- SU*i y*{i,t} + SD*i z*{i,t}

  \Big).

  ]

---

## 5. 基态 UC 机组约束（Classical UC 部分）

### 5.1 出力上下限

[

P*i^{\min} u*{i,t} \le P*{i,t} \le P_i^{\max} u*{i,t},

\quad \forall i\in\mathcal{I},\ \forall t\in\mathcal{T}.

]

### 5.2 启停逻辑

[

u*{i,t} - u*{i,t-1} = y*{i,t} - z*{i,t},

\quad \forall i,\ \forall t>1,

]

[

y*{i,t} + z*{i,t} \le 1,

\quad \forall i,\ \forall t.

]

（(t=1) 时结合初始状态 (U_i^0,T_i^0) 处理。）

### 5.3 最小开机时间

[

\sum*{\tau=t}^{t+UT_i-1} u*{i,\tau} \ge UT*i \cdot y*{i,t},

\quad \forall i,\ \forall t: t+UT_i-1\le T.

]

### 5.4 最小停机时间

[

\sum*{\tau=t}^{t+DT_i-1} (1-u*{i,\tau}) \ge DT*i \cdot z*{i,t},

\quad \forall i,\ \forall t: t+DT_i-1\le T.

]

### 5.5 爬坡约束

[

P*{i,t} - P*{i,t-1} \le RU_i,

\quad \forall i,\ \forall t>1,

]

[

P*{i,t-1} - P*{i,t} \le RD_i,

\quad \forall i,\ \forall t>1.

]

---

## 6. 基态网络与 DC 潮流约束

### 6.1 母线功率平衡

对每个 (b\in\mathcal{B})、(t\in\mathcal{T})：

# [

\sum*{i\in\mathcal{I}(b)} P*{i,t} - D\_{b,t}

## \sum* F*

\sum*{\ell\in\delta^-(b)} F*{\ell,t}.

]

### 6.2 DC 潮流方程

# [

F\_{\ell,t}

\frac{\theta*{\text{from}(\ell),t} - \theta*{\text{to}(\ell),t}}{x\_\ell},

\quad \forall \ell\in\mathcal{L},\ \forall t\in\mathcal{T}.

]

### 6.3 线路容量限制

[

- F*\ell^{\max} \le F*{\ell,t} \le F\_\ell^{\max},

  \quad \forall \ell\in\mathcal{L},\ \forall t\in\mathcal{T}.

  ]

### 6.4 参考母线

选定一个母线 (b_0\in\mathcal{B})：

[

\theta\_{b_0,t} = 0,\quad \forall t\in\mathcal{T}.

]

---

## 7. 机组级旋转备用约束

### 7.1 每台机组的备用上限

[

0 \le R*{i,t} \le P_i^{\max} u*{i,t} - P\_{i,t},

\quad \forall i\in\mathcal{I},\ \forall t\in\mathcal{T}.

]

### 7.2 系统总备用需求（基于 load step）

[

\sum*{i\in\mathcal{I}} R*{i,t} \ge R_t = 600,

\quad \forall t\in\mathcal{T}.

]

---

## 8. 最小惯性约束

对每个时段 (t\in\mathcal{T})：

[

\sum*{i\in\mathcal{I}} H_i u*{i,t} ;\ge; H^{\min},

]

其中

[

H^{\min}

= \frac{600}{2 \cdot 2.118 \cdot 0.5}.

]

保证在 600 MW 负荷阶跃下，ROCOF 不超过 0.5 Hz/s。

---

## 9. 严格 N−1：机组故障场景 (g\in\mathcal^G)

对每个故障机组 (g\in\mathcal{I})、每个时段 (t\in\mathcal{T})：

### 9.1 出力与增量关系

[

P*{i,t}^{(g)} = P*{i,t} + \Delta P\_{i,t}^{(g)},

\quad \forall i\in\mathcal{I}.

]

### 9.2 故障机组停运

[

P\_{g,t}^{(g)} = 0,

\quad \forall t\in\mathcal{T}.

]

### 9.3 再调度不超过备用 + 物理出力界

对所有 (i\neq g)：

[

0 \le \Delta P*{i,t}^{(g)} \le R*{i,t},

\quad \forall i\neq g,\ \forall t\in\mathcal{T},

]

[

0 \le P*{i,t}^{(g)} \le P_i^{\max} u*{i,t},

\quad \forall i\neq g,\ \forall t\in\mathcal{T}.

]

（故障机组 (g) 的 (P\_{g,t}^{(g)}=0)，不再承担负荷。）

### 9.4 母线功率平衡（机组故障场景）

# [

\sum*{i\in\mathcal{I}(b)} P*{i,t}^{(g)} - D\_{b,t}

## \sum* F*^

\sum*{\ell\in\delta^-(b)} F*{\ell,t}^{(g)},

\quad \forall b\in\mathcal{B},\ \forall t\in\mathcal{T}.

]

### 9.5 DC 潮流与线路限额（机组故障场景）

[

F\_{\ell,t}^{(g)} =

\frac{\theta*{\text{from}(\ell),t}^{(g)} - \theta*{\text{to}(\ell),t}^{(g)}}{x\_\ell},

\quad \forall \ell\in\mathcal{L},\ \forall t\in\mathcal{T},

]

[

- F*\ell^{\max} \le F*{\ell,t}^{(g)} \le F\_\ell^{\max},

  \quad \forall \ell\in\mathcal{L},\ \forall t\in\mathcal{T}.

  ]

### 9.6 参考母线（机组故障场景）

[

\theta\_{b_0,t}^{(g)} = 0,

\quad \forall t\in\mathcal{T}.

]

---

## 10. 严格 N−1：线路故障场景 (\ell\in\mathcal^L)

对每条线路 (\ell\in\mathcal{L})、每个时段 (t\in\mathcal{T})：

### 10.1 出力与增量关系

[

P*{i,t}^{[\ell]} = P*{i,t} + \Delta P\_{i,t}^{[\ell]},

\quad \forall i\in\mathcal{I}.

]

### 10.2 再调度不超过备用 + 物理出力界

[

0 \le \Delta P*{i,t}^{[\ell]} \le R*{i,t},

\quad \forall i\in\mathcal{I},\ \forall t\in\mathcal{T},

]

[

0 \le P*{i,t}^{[\ell]} \le P_i^{\max} u*{i,t},

\quad \forall i\in\mathcal{I},\ \forall t\in\mathcal{T}.

]

### 10.3 故障线路切除

[

F\_{\ell,t}^{[\ell]} = 0,

\quad \forall t\in\mathcal{T}.

]

### 10.4 母线功率平衡（线路故障场景）

# [

\sum*{i\in\mathcal{I}(b)} P*{i,t}^{[\ell]} - D\_{b,t}

## \sum* F*^

\sum*{\ell'\in\delta^-(b)} F*{\ell',t}^{[\ell]},

\quad \forall b\in\mathcal{B},\ \forall t\in\mathcal{T}.

]

### 10.5 DC 潮流与线路限额（其它线路）

对所有 (\ell' \in \mathcal{L},\ \ell'\neq \ell)：

[

F\_{\ell',t}^{[\ell]} =

\frac{\theta*{\text{from}(\ell'),t}^{[\ell]} - \theta*{\text{to}(\ell'),t}^{[\ell]}}{x\_{\ell'}},

\quad \forall \ell'\neq\ell,\ \forall t\in\mathcal{T},

]

[

- F*{\ell'}^{\max} \le F*{\ell',t}^{[\ell]} \le F\_{\ell'}^{\max},

  \quad \forall \ell'\neq\ell,\ \forall t\in\mathcal{T}.

  ]

### 10.6 参考母线（线路故障场景）

[

\theta\_{b_0,t}^{[\ell]} = 0,

\quad \forall t\in\mathcal{T}.

]

补充:

---

* 负荷均匀分布：

  [

  D_{b,t} = \frac{D_t}{|\mathcal{B}|}

  ]
